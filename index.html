01 / INTRODUCTION

Основы SQL

SQL — язык запросов для работы с базами данных. Он позволяет создавать, находить, изменять и удалять данные.

База данных

Организованное хранилище информации.

СУБД

Программа для работы с БД: SQLite, MySQL, PostgreSQL.

02 / DATABASE STRUCTURE

Создание таблиц

CREATE TABLE

Создание

Создаёт новую таблицу с указанными столбцами и типами данных.

CREATE TABLE books (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  genre TEXT,
  price INTEGER,
  rating INTEGER
);
Разбор:

INTEGER — целое число; TEXT — текст; PRIMARY KEY — уникальный идентификатор; AUTOINCREMENT — автоматическая нумерация; NOT NULL — обязательное поле.

INSERT INTO

Добавление

Добавляет новые записи в таблицу.

INSERT INTO books (title, genre, price, rating)
VALUES ('Гарри Поттер', 'Фэнтези', 4500, 9);
В таблицу добавится книга «Гарри Поттер». Текст записывается в одинарных кавычках, а числа — без них.

DROP TABLE

Удаление таблицы
DROP TABLE books;
Важно! Удаляется вся таблица вместе со всеми данными, а не одна запись.
03 / MODIFY DATA

Изменение данных

UPDATE + SET

UPDATE изменяет существующие записи. SET указывает новое значение.

UPDATE books
SET price = 5000
WHERE id = 1;
У книги с id = 1 цена изменится на 5000.
UPDATE books
SET price = price + 500
WHERE genre = 'Фэнтези';
Цена всех книг жанра «Фэнтези» увеличится на 500.

DELETE FROM

Удаляет строки, подходящие под условие.

DELETE FROM books
WHERE price < 3500;
Удалятся все книги дешевле 3500.
Если забыть WHERE, DELETE удалит все строки, а UPDATE изменит все строки.
04 / SELECT DATA

Выборка данных

SELECT и FROM

SELECT — какие столбцы показать. FROM — из какой таблицы.

SELECT * FROM books;
Звёздочка * означает все столбцы.
SELECT title, price
FROM books;
Выведет только названия книг и цены.

ORDER BY

Сортирует результат запроса.

SELECT * FROM books
ORDER BY price ASC;
ASC — по возрастанию, от дешёвых к дорогим.
SELECT * FROM books
ORDER BY price DESC;
DESC — по убыванию, от дорогих к дешёвым.

LIMIT

Ограничивает количество выводимых строк.

SELECT * FROM books
ORDER BY price DESC
LIMIT 3;
Покажет три самые дорогие книги.

DISTINCT

Убирает повторяющиеся значения в результате.

SELECT DISTINCT genre
FROM books;
Выведет каждый жанр только один раз.
05 / FILTERING

Фильтрация данных

WHERE

Отбирает строки по условию.

SELECT * FROM books
WHERE price > 4000;
Выведет книги дороже 4000.
=Равно
!=Не равно
>Больше
<Меньше
>=Больше или равно
<=Меньше или равно

AND / OR / NOT

AND — оба условия должны выполняться.

SELECT * FROM books
WHERE genre = 'Фэнтези'
AND price < 5000;
Книги жанра «Фэнтези», которые дешевле 5000.

OR — достаточно одного условия.

SELECT * FROM books
WHERE genre = 'Классика'
OR rating = 10;
Книги жанра «Классика» или книги с рейтингом 10.

NOT — отрицание условия.

SELECT * FROM books
WHERE NOT genre = 'Фэнтези';
Книги, жанр которых не «Фэнтези».

BETWEEN

Проверяет диапазон значений, включая границы.

SELECT * FROM books
WHERE price BETWEEN 3000 AND 5000;
Выведет книги с ценой от 3000 до 5000 включительно.

IN

Проверяет, входит ли значение в список.

SELECT * FROM books
WHERE genre IN ('Фэнтези', 'Классика');
Выведет книги двух указанных жанров. IN заменяет несколько условий OR.

LIKE

Используется для поиска текста по шаблону.

%Любое количество символов
_Ровно один символ
SELECT * FROM books
WHERE title LIKE 'Г%';
Название начинается на «Г».
SELECT * FROM books
WHERE title LIKE '%т';
Название заканчивается на «т».
SELECT * FROM books
WHERE title LIKE '___';
Название состоит ровно из трёх символов.

LIKE с датами

SELECT * FROM books
WHERE publish_date LIKE '2024-05-%'
OR publish_date LIKE '2024-06-%'
ORDER BY price ASC;
Выведет книги, опубликованные в мае или июне 2024 года, по возрастанию цены. Даты должны храниться в формате YYYY-MM-DD.
06 / AGGREGATE FUNCTIONS

Агрегатные функции

Позволяют считать количество, сумму, среднее, минимум и максимум.

COUNT()

Количество записей

SUM()

Сумма значений

AVG()

Среднее значение

MIN()

Минимум

MAX()

Максимум

AS

Псевдоним столбца

COUNT()

SELECT COUNT(*) AS total
FROM books;
Посчитает количество книг. Для нашей таблицы ответ: 4.

SUM() и AVG()

SELECT SUM(price) AS total_price,
       AVG(price) AS average_price
FROM books;
SUM сложит все цены, AVG найдёт среднюю цену.

MIN() и MAX()

SELECT MIN(price) AS cheapest,
       MAX(price) AS expensive
FROM books;
Минимальная цена — 3200, максимальная — 5100.
07 / GROUPING

GROUP BY и HAVING

GROUP BY

Объединяет записи с одинаковыми значениями в группы.

SELECT genre, COUNT(*) AS total
FROM books
GROUP BY genre;
Посчитает, сколько книг относится к каждому жанру.
genretotal
Фэнтези2
Классика1
Антиутопия1

HAVING

Фильтрует группы после группировки.

SELECT genre, COUNT(*) AS total
FROM books
GROUP BY genre
HAVING COUNT(*) > 1;
Оставит только жанры, в которых больше одной книги. Ответ: Фэнтези — 2.

WHERE

Фильтрует отдельные строки до группировки.

HAVING

Фильтрует готовые группы после группировки.

Комбинированный запрос

SELECT genre, COUNT(*) AS total
FROM books
WHERE price > 3000
GROUP BY genre
HAVING COUNT(*) > 1
ORDER BY total DESC;
Сначала выбираем книги дороже 3000, затем группируем их по жанру. Оставляем жанры, в которых больше одной книги, и сортируем результат.

🔗 JOIN — объединение таблиц

🔗 JOIN — объединение таблиц

JOIN используется, чтобы объединить данные из двух или нескольких таблиц по общему полю.

Пример двух таблиц

Таблица students:

idnamegenre_id
1Алия1
2Данияр2
3АружанNULL

Таблица genres:

idgenre_name
1Фэнтези
2Детектив
3Комедия
Как связаны таблицы?
students.genre_id указывает на genres.id. По этим столбцам мы будем объединять данные.
INNER JOIN

1. INNER JOIN — только совпадения

Выводит только те строки, для которых нашлось совпадение в обеих таблицах. 

SELECT students.name, genres.genre_name
FROM students
INNER JOIN genres
ON students.genre_id = genres.id;

Результат:

namegenre_name
АлияФэнтези
ДаниярДетектив
Аружан не выводится, потому что у неё нет жанра. Комедия тоже не выводится, потому что с ней нет ученика.
LEFT JOIN

2. LEFT JOIN — все из левой таблицы

Выводит все строки из таблицы слева (students), даже если совпадения нет. 

SELECT students.name, genres.genre_name
FROM students
LEFT JOIN genres
ON students.genre_id = genres.id;

Результат:

namegenre_name
АлияФэнтези
ДаниярДетектив
АружанNULL
Аружан осталась в результате, потому что LEFT JOIN сохраняет все строки левой таблицы. NULL означает отсутствие значения.
RIGHT JOIN

3. RIGHT JOIN — все из правой таблицы

Выводит все строки из таблицы справа (genres), даже если совпадения нет. 

SELECT students.name, genres.genre_name
FROM students
RIGHT JOIN genres
ON students.genre_id = genres.id;

Результат:

namegenre_name
АлияФэнтези
ДаниярДетектив
NULLКомедия
Комедия осталась, потому что находится в правой таблице. Аружан не выводится.
FULL JOIN

4. FULL JOIN — все из обеих таблиц

Выводит все строки из обеих таблиц. Если совпадения нет, появляется NULL. 

SELECT students.name, genres.genre_name
FROM students
FULL JOIN genres
ON students.genre_id = genres.id;

Результат:

namegenre_name
АлияФэнтези
ДаниярДетектив
АружанNULL
NULLКомедия
FULL JOIN сохраняет и Аружан, и Комедию, даже без совпадений.
DOUBLE JOIN

5. Двойной JOIN — три таблицы

Используется, когда две таблицы связаны через третью, промежуточную таблицу. 

SELECT Readers.name, Clubs.club_name
FROM Readers
INNER JOIN Reader_Club
ON Readers.id = Reader_Club.reader_id
INNER JOIN Clubs
ON Clubs.id = Reader_Club.club_id;
Пошагово:
1. Берём таблицу Readers.
2. Соединяем её с Reader_Club.
3. Соединяем результат с Clubs.
4. Получаем имена читателей и названия клубов, в которых они состоят.

🧠 Как запомнить JOIN?

Команда Что выводит?
INNER JOIN Только совпадения
LEFT JOIN Все строки слева
RIGHT JOIN Все строки справа
FULL JOIN Все строки с обеих сторон
Двойной JOIN Соединение через третью таблицу
💡 Запомни: ON указывает, по каким столбцам соединять таблицы. NULL означает отсутствие значения.
